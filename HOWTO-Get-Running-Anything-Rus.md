# Какие двигатели поддерживает проект rusEFI?
## По типу топливу
rusEFI поддерживает бензиновые двигатели, поддержка дизельных двигателей пока не предусмотрена.

## По типу впрыска
### Центральный впрыск (моновпрыск)
Тип впрыска, при котором одна форсунка подаёт топливо в общий впускной коллектор, где оно смешивается с воздухом. По сути, это аналог карбюратора с форсункой.

### Распределенный впрыск 
В этой системе для каждого цилиндра предусмотрена отдельная форсунка, которая подаёт топливо во впускной коллектор вблизи впускного клапана.

### Непосредственный впрыск
В этой системе топливо подаётся отдельными форсунками напрямую в камеру сгорания каждого цилиндра под высоким давлением вместе с воздухом.
